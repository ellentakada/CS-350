***Summarize the project and what problem it was solving.***
- I developed a temperature reading program using a TI board. It has functions to read the temperature, increase or decrease it with the buttons, and report it to a server. 
***What did you do particularly well?***
  - I learned different drivers (I2C, GPIO, UART) to achieve functions. Throughout the course, I learned different capabilities of each driver, such as lighting LED periodically.
***Where could you improve?***
- TI board comes with many drivers and features, so I want to explore what I can do with it. For instance, I want to control the frequency of LED by buttons.
***What tools and/or resources are you adding to your support network?***
  - I had a tutor who supported along the course, but also official documents helped immensely in understanding each driver. They come with a sample code, with a description of each function.
***What skills from this project will be particularly transferable to other projects and/or course work?***
- C++ is a common language used to develop low-level software such as embedded systems. If I were to develop an IoT product, the knowledge and skills I gained through the course will help me.
***How did you make this project maintainable, readable, and adaptable?***
  - I stayed curious about the drivers and how I can achieve functionalities. What kept me motivated was the result I can see through the TI board; it felt great when LED started flashing after developing a code. I made an effort to make the code readable by adding comments and line spaces.
